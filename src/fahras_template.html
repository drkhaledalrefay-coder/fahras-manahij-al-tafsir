    دليل الواجهة

    1. القراءة

    • التفسير: اختيار كتاب التفسير المعروض.
    • الآية: اختيار النافذة النصية / الآية.
    • النموذج: أي نموذج اقترح التمييزات (نفس المنهج والمدقق).
    • اعرض الأصل بجانبه: مقارنة حرفية مع نص المصدر.
    • فاتح/داكن: تبديل مظهر الصفحة.

    2. لوحة المناهج

    • الألوان + الخط السفلي: كل منهج بلون ونمط؛ لا تعتمد على اللون وحده.
    • أساسي / مساعد: التعبئة = أساسي؛ النقاط والخط المتقطع = مساعد.
    • اليقين: صريح / مستنتج بقوة / مستنتج بضعف / امتناع.
    • مرشح للقبول مقابل بانتظار المتخصص: مسار الاقتراح.
    • علامات النص فقط: عبارات مثل «قال ابن عباس» بلا اقتراحات النموذج.

    3. جدول النتائج

    • حروف / فقرات: حجم النافذة وعدد الفقرات.
    • تحركات: مواضع مقترحة من النموذج.
    • مرشّح للقبول / للمتخصص: توزيع المسارات.
    • أعلام: تنبيهات من مدقق القواعد.
    • امتناع / توزيع المناهج: حالات الامتناع وعدد كل منهج.
    • التشغيل ١ و٢: مقارنة قبل وبعد تشديد المدقق إن وُجدت.

    4. درج الموضع

    • لماذا؟ والدليل: التعليل والبيان وأجزاء الدرجة.
    • وميض الدليل: يضيء الكلمات التي استند إليها.
    • الوسوم: أساسي / مساعد / نوع محتوى.
    • الحدود: توسيع أو تقليص بالكلمات والجمل.
    • المقارنة والاعتماد: قارن ثم اعتمد أو عدّل أو ارفض.

    5. أدوات المراجعة

    • + كلمة قبل / − أول كلمة / + كلمة بعد / − آخر كلمة: ضبط الحدود كلمة بكلمة.
    • دمج / توسيع إلى الجملة / استعادة اقتراح الآلة: تعديلات أوسع أو رجوع.
    • تغيير المنهج / حذف / امتناع: إعادة الوسم أو الحذف بعد تأكيد أو الامتناع عن الوسم.
    • يحتاج تعديل / رفض / قارن بالمصدر / اعتماد: قرارات المراجعة.

    6. التصدير

    • هذا الموضع (JSON): سجل التمييز المحدد للمراجعة أو الأرشفة.
    • كل المعتمد (JSON): ما اعتمده المتخصص فقط — صالح للنشر الداخلي.
    • سجل التعديلات: قرارات المتخصص وحدودها لمن راجع ماذا.
    • Label Studio: للباحثين الذين يستوردون الوسم في أداة خارجية.

    7. قواعد الأمانة

    • النص لا يُعدَّل؛ الحدود تلتصق بالكلمات فقط.
    • حاشية المحقق لا تُوسم بمنهج المؤلف.
    • لا يُنشر إلا المعتمد بعد المقارنة بالمصدر.

    كيف يعمل الموقع

    صفحة واحدة ثابتة؛ البيانات مضمّنة فيها. لا خادم، وتعمل دون اتصال بعد فتح الملف.

    1. النص من المصدر ببصمة رقمية
    2. تقطيع إلى أجزاء مرقّمة وفصل حاشية المحقق
    3. علامات نصية يلتقطها البرنامج (بلا ذكاء اصطناعي)
    4. النموذج يقترح منهج كل موضع ويشير إلى الدليل بأرقام الأجزاء فقط
    5. مدقق قواعد مستقل يحسب الدرجة ويوجّه (مرشح للقبول / للمتخصص)
    6. المتخصص يراجع بقلم التمييز ويقارن بالمصدر ثم يعتمد
    7. ملف JSON معتمد لتطبيقات القرآن

    النموذج قابل للاستبدال: نفس المهارة شغّلت بنماذج مختلفة، فتُقارن النتائج دون تغيير المنهج أو المدقق.

    التشغيل ١ قبل تشديد المدقق؛ التشغيل ٢ بعد تشديد عام لكل التفاسير — لا ضبط على تفسير بعينه.
