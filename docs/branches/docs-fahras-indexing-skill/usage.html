فهرسة مناهج التفسير: مهارة تشغيل الوكيلين

مهارة المشروع (fahras-tafsir-indexing) لوكلاء مشغّل الذكاء: من عيّنة ٢٤:٣٥ إلى الوسم الجماعي لسورة النور — يفهرس المنهج ولا يفسّر ولا يعتمد
السلسلة:نافذة مثبّتة ← حزمة وبصمة ← وكيل من عائلة Qwen + وكيل من عائلة أخرى ← الفاحص لكل وكيل ← رئيس اللجنة ← مرشّح للمراجعة أو امتناع برمز واحد ← المتخصص يعتمد
الطبقة ١ — الفاحص (٧٥): لكل وكيل وحده: شاهد صريح، بوابة الكفاية، بصمة مطابقة، يقين صريح أو قوي، درجة ٧٥ فأكثر، بلا أعلام.
الطبقة ٢ — رئيس اللجنة (٨٥): الوكيلان مرشّحان، نفس المنهج، تداخل أجزاء، درجة المصنّف ٨٥ فأكثر، عائلتان مختلفتان. ليستا تعارضاً، ولا واحدة منهما اعتماد.
1

حمّل المهارة في الوكيل

انسخ مجلد المهارة إلى مجلد مهارات وكيلك (Claude Code أو Codex).

Copy-Item -Recurse docs/team/skills/fahras-tafsir-indexing $HOME/.claude/skills/
الناتج المتوقع: يظهر اسم المهارة في قائمة مهارات الوكيل.
توقّف إن لم تظهر: تحقّق من المسار قبل أي تشغيل.
2

تحقّق ثم افتح فرعك

على main المحدّث، ثم فرع خاص بالوسم. لا عمل على main.

python -m pytest -q python src/v2_selftest.py
الناتج المتوقع: الاختبارات ناجحة و SELFTEST PASS.
توقّف إن فشل أي اختبار: لا تشغيل على كود غير سليم.
3

نموذجان من عائلتين

اسحب النموذجين وسجّل الوسم الفعلي. اسم مجلد الوكيل يُشتق من اسم النموذج.

ollama pull qwen2.5:32b ollama pull gemma3:27b ollama list
الناتج المتوقع: المجلدان qwen2_5_32b و gemma3_27b بعد التشغيل.
توقّف إن كان النموذجان من العائلة نفسها: الرئيس يرفضهما.
4

العيّنة ٢٤:٣٥ بالوكيلين

فحص بلا شبكة أولاً، ثم الوكيلان على النافذة نفسها. الفاحص يعمل تلقائياً بعد كل تشغيل.

python src/run_window.py --tafsir al_tabari --base data/nur/al_tabari --window 24_35_p01 --api --model qwen2.5:32b
الناتج المتوقع: سطر verifier بعدد المرشّح والمحال.
توقّف إن ظهر سجل فشل متكرر: ارفع السياق ولا تعدّل الفاحص.
5

رئيس اللجنة ثم المراجعة

الرئيس يقرأ مخرجي الوكيلين ولا يعدّلهما. بعد العيّنة: توقّف للمراجعة العمياء والشرعية.

python src/committee_chair.py --base data/nur/al_tabari --proposer qwen2_5_32b --reviewer gemma3_27b --window 24_35_p01
الناتج المتوقع: ملف committee للنافذة بقرار ورمز لكل حركة.
توقّف إن جاءت كل الحركات اتفاقاً: علامة شك لا نجاح.
6

الجماعي والتسجيل

بعد قبول العيّنة فقط: حلقة على نوافذ كل تفسير لكل وكيل، ثم الرئيس على الكل، ثم commit لكل تفسير.

python src/committee_chair.py --base data/nur/al_tabari --proposer qwen2_5_32b --reviewer gemma3_27b --all
الناتج المتوقع: فرع ثم PR ثم CI أخضر، والرسالة فيها الوسمان الفعليان.
توقّف إن طُلب خفض ٧٥ أو ٨٥: القرار لقائد الفريق.
EVIDENCE_EMPTYلا شاهد صريح — لا يولّد الفاحص شاهداً بديلاً
UNGROUNDED_CLAIMمرجع أو ادعاء معروض بلا شاهد يسنده
PACKET_HASH_MISMATCHبصمة الحزمة في الرد لا تطابق الحزمة الحالية
agent_disagreeاختلاف الوكلاء (المنهج الرئيسي مختلف)
unclear_boundsحدود غير واضحة أو تقطيع بلا تقاطع
weak_evidenceدليل ضعيف أو درجة المصنّف دون ٨٥
ما لا تفعله المهارة: لا تفسير ولا فتوى، لا اعتماد آلي، لا تعديل على النص المثبّت، لا نسب ولا ادعاء دقة — أعداد توجيه وليست دقة.
كيف تعرف أنها تعمل: سطر verifier بعد كل نافذة، وملفات verified و committee على القرص، وأي فشل يظهر سجلاً واحداً برمز.
