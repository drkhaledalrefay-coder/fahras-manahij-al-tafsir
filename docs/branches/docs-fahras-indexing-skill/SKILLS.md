## ١. مهارة وسم مناهج التفسير (`tafsir-methods-tagging`)
- **الملف:** `docs/team/skills/tafsir-methods-tagging/SKILL.md`
  - مراجع المهارة:
    - `docs/team/skills/tafsir-methods-tagging/references/methods.md` (جدول رموز المناهج ومستويات اليقين)
    - `docs/team/skills/tafsir-methods-tagging/references/reason-codes.md` (جدول رموز الامتناع الستة عشر المغلقة)
    - `docs/team/skills/tafsir-methods-tagging/references/runbook.md` (دفتر التشغيل وأعلام الأوامر الحقيقية)
- **لماذا:** تمكين وتوجيه مشغّل الذكاء الاصطناعي (Ollama على جهاز GPU) من تشغيل عملية منضبطة حيث يعمل وكيلان من عائلتين مختلفتين لوسم مناهج التفسير لسورة النور عبر مسار تدريجي يبدأ بالتشغيل الجاف (`--dry-run`)، ثم فحص عيّنة الآية 24:35 والتوقف للمراجعة البشرية، ثم الوسم الجماعي، مع التزام تام بعدم المساس بنصوص التفسير الأصلية واعتبار الأرقام أعداد توجيه وليست دقة، إذ لم ندرّب نماذج خاصة.
- **طريقة التحميل والاستخدام:** نسخ مجلد المهارة إلى مجلد مهارات الوكيل المستخدم (مثل `.claude/skills/` في Claude Code أو المجلد المماثل في Codex)، أو توجيه الوكيل مباشرة لقراءة الملف عبر موجه الأوامر.
