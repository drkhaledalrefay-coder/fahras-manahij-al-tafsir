عقد الإسناد: من النافذة إلى المراجعة

قاعدة المسابقة: سؤال ← استرجاع ← هل الدليل كافٍ؟ ← نعم: صياغة مسندة / لا: امتناع أو إحالة
المسار:نافذة مثبّتة ← حزمة وبصمة ← اقتراح بمعرّفات الأجزاء ← فحص حتمي (بوابة الكفاية) ← مرشّح للمراجعة أو امتناع برمز سبب واحد ← المتخصص يعتمد
1

نافذة مثبّتة وحزمة

نص المصدر ثابت بالبصمة؛ الحزمة أجزاء مرقّمة فقط بلا تفسير.

python src/run_window.py --tafsir al_tabari --window 24_35_p01 --base data/nur/al_tabari --dry-run
الناتج المتوقع: عدد الأجزاء وبصمة الحزمة المعروضة.
توقّف هنا إن ظهر خطأ في الحزمة قبل أي شبكة.
2

اقتراح بمعرّفات الأجزاء

النموذج يقترح حدوداً وشواهد بمعرّفات الأجزاء فقط، مربوطاً ببصمة الحزمة.

python src/run_window.py --tafsir al_tabari --window 24_35_p01 --base data/nur/al_tabari --api --model qwen2.5:32b --base-url http://localhost:11434/v1
الناتج المتوقع: مسار ملف الحركات المحفوظ.
توقّف هنا إن ظهر سجل فشل بدل مسار الملف.
3

بوابة الكفاية الحتمية

الفاحص يتحقق من المصدر والحدود وكفاية الشاهد؛ الدرجة مؤشر لا إثبات.

python src/v2_verify.py --base data/nur/al_tabari
الناتج المتوقع: مرشّح للمراجعة أو محال للمتخصص.
توقّف هنا إن بقيت الحركة عند المتخصص رغم الدرجة العالية.
4

سجل الفشل المغلق

أي تعذّر تشغيل أو رد فاسد يُسجَّل سجلاً واحداً ولا يُكتب ملف حركات.

{"window_id": "24_35_p01", "status": "failed", "reason_code": "RUN_FAILURE"}
الناتج المتوقع: خروج غير صفري مع السجل مطبوعاً.
توقّف هنا إن طُبع أثر خطأ خام بدل السجل.
5

اليدوي غير مضمون أبداً

الرد الملصوق من أي محادثة موسوم غير مضمون المدخل ولا يُرشَّح آلياً.

python src/run_window.py --tafsir al_tabari --window 24_35_p01 --base data/nur/al_tabari --manual-in reply.json
الناتج المتوقع: رسالة غير مضمون ومراجعة متخصصة فقط.
توقّف هنا إن طُلب ترشيح اليدوي آلياً — ممنوع.
6

المتخصص يعتمد

كلمة الاعتماد للمتخصص البشري وحده بعد فحص الدلالة والمصدر.

python -m pytest tests/test_grounding_verifier.py tests/test_grounding_io.py -q
الناتج المتوقع: خمسة وعشرون اختباراً ناجحاً.
توقّف هنا إن فشل أي اختبار قبل التشغيل الجماعي.
RUN_FAILUREتعذّر التشغيل (شبكة/مهلة/خطأ نموذج) — لا اقتراح
PACKET_HASH_MISMATCHبصمة الحزمة في الرد لا تطابق الحزمة الحالية
MANUAL_INPUT_UNVERIFIEDرد يدوي من محادثة خارجية — المدخل غير مضمون
EVIDENCE_EMPTYلا شاهد صريح — لا يولّد الفاحص شاهداً بديلاً
UNGROUNDED_CLAIMمرجع أو ادعاء معروض بلا شاهد يسنده
INSUFFICIENT_EVIDENCEبوابة كفاية الدليل لم تُجتز
ما لا يفعله هذا الفرع: لا تدريب نماذج، لا ترشيح آلي، لا تعديل على بيانات المصدر، لا أرقام دقة.
كيف تعرف أنه يعمل: شغّل الفحص الذاتي ثم الاختبارات — الناتج المتوقع نجاح كامل بلا فشل.
