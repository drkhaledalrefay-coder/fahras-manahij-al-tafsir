تهيئة الطرفية وسحب النماذج

متغيرات بيئة الجلسة فقط (PowerShell):

$env:PYTHONIOENCODING = "utf-8" $env:LLM_API_KEY = "ollama" $env:LLM_BASE_URL = "http://localhost:11434/v1"

سحب نماذج عائلتين مختلفتين وتوثيق الوسم:

ollama pull qwen2.5:32b ollama pull gemma3:27b ollama list
يُسجّل الوسم الفعلي الظاهر في القائمة حرفياً.

الفحص الجاف وعيّنة 24:35

فحص سلامة الحزمة محلياً بدون شبكة:

python src/run_window.py --tafsir al_tabari --window 24_35_p01 --base data/nur/al_tabari --dry-run

تشغيل العيّنة عبر API للتفاسير الأربعة:

الوسم الجماعي والفحص الحتمي

بعد اعتماد العيّنة: تشغيل سورة النور كاملة:

python src/run_surah.py --db "quran.db" --tafsir al_tabari --surah 24 --base data/nur/al_tabari --classify --time-cap 300

تشغيل الفاحص الحتمي للتحقق من الشواهد:

python src/v2_verify.py --base data/nur/al_tabari
التحقق من الحدود والشواهد؛ كل شك = امتناع وإحالة برمز سبب.
