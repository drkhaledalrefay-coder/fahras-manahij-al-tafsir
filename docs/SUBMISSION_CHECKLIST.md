# قائمة التحقق قبل التسليم

بوابة يدوية تُراجَع قبل الموعد (٦ أكتوبر ٢٠٢٦، ١١:٥٩ م بتوقيت الرياض، حسب `method/competition_rules_checklist.md`). طابِقوا البنود مع الموقع الحي قبل الاعتماد عليها. الحالة أدناه كما فُحصت في ٢ أكتوبر ٢٠٢٦ (التفصيل في [`AUDIT_2026-10-02.md`](AUDIT_2026-10-02.md)).

**لا يُشطب بند إلا بدليل:** أمر شُغِّل ونتيجته، أو رابط، أو قرار مكتوب.

## ١. قرارات تسبق كل شيء (P0)

- [ ] **النطاق:** تفسير واحد (الطبري) أم أربعة للأنفال؟ وهل اختبار A/B على ابن كثير ضمن البناء؟ (جواب المرشد مكتوب)
- [ ] **مصدر النص المفهرَس:** هل يجب أن يكون من الدرر السنية (توجيه المالك)، أم تكفي بيانات مركز تفسير الحالية؟ (جواب مكتوب)
- [ ] لكل تفسير مستعمل: المصدر، والطبعة، والرابط، والترخيص، و**حق إعادة النشر في مستودع عام**، مسجَّلة في `ATTRIBUTION.md`
- [ ] الفصل واضح في الوثائق بين مصدر **النص المفهرَس** ومصدر **أي شرح أو جواب شرعي**

## ٢. بوابة جعل المستودع عاماً (يقرّرها المالك يدوياً)

- [ ] فحص أسرار متخصص على الملفات **والسجل** (مثل GitHub Secret Scanning)
- [ ] لا بيانات شخصية ولا ملاحظات خاصة ولا محادثات حقيقية في الملفات أو السجل
- [ ] كل نص منشور في المستودع مسموح بنشره (البند ١)
- [ ] موافقة الفريق
- [ ] تغيير الرؤية إلى «عام» — **من المالك فقط**

## ٣. المنتج يعمل (P1)

- [ ] إعداد نظيف على جهاز جديد: `pip install -r requirements.txt` ثم `python src/build_fahras.py` ثم فتح `web/fahras.html`
- [ ] `python src/v2_selftest.py` يطبع `SELFTEST PASS`
- [ ] `python -m unittest discover -s tests -p "test_*.py"` ناجح (واذكروا المتخطّى إن غاب `QURAN_DB`)
- [ ] `python deck/qa/qa_runner.py` يخرج برمز ٠ (الخادم على 8791)
- [ ] سلسلة كاملة على نافذة أنفال واحدة على الأقل: اقتراح ← تحقق حتمي ← مراجعة ← اعتماد متخصص ← `export_approved.py`
- [ ] البديل اليدوي مجرَّب دون مفتاح: `--manual-out` ثم `--manual-in`
- [ ] الواجهة تميّز «مقترح آلي» عن «معتمد»، ولا تُعرض أرقام اعتماد غير حقيقية
- [ ] رابط عرض حي ثابت يعمل من شبكة خارجية طوال فترة التحكيم

## ٤. ملفات التسليم

- [ ] مستودع GitHub عام (البند ٢)
- [ ] وثائق التشغيل: `docs/RUN.md` و`docs/AI_RUN.md`
- [ ] سجل المصادر والتراخيص: `ATTRIBUTION.md` (محدَّث بعد البند ١)
- [ ] الإفصاح عن أدوات الذكاء الاصطناعي: `docs/AI_DISCLOSURE.md`
- [ ] العرض التقديمي (PDF أو PowerPoint)
- [ ] فيديو لا يتجاوز **دقيقتين**
- [ ] لا ادعاء دقة أو اعتماد أو تغطية دون دليل في المستودع
