ALREADY BUILT (reuse, do not redesign from scratch):
- Code-only download of the source, sha256-pinned; the AI never writes or retypes text. Text is cut by CODE into numbered spans; annotators return span IDs + tags only; units are rebuilt from the pinned source and verified verbatim (100% in pilot).
- The digital text embeds the EDITOR's apparatus inline: footnotes delimited ¬...¥ (hadith takhrij and gradings like «وسنده صحيح», manuscript variants), verse refs like [النساء: 166], and other [ ... ] insertions of uncertain provenance. Code already separates author vs editor layers. KEY IDEA: editor footnotes are NOT Ibn Kathir's words, but they are ready-made scholarly adjudication (hadith grading, source identification) usable as an EVIDENCE layer.
- Ibn Kathir's own introduction adopts the known hierarchy of the best methods of tafsir (Qur'an by Qur'an, then Sunnah, then Sahabah, then Tabi'in) — a methodological authority from the author himself (verify wording and location in the source before quoting).
- Pilot: 3 ayat (2:255, 17:105, 2:102), 143 spans; two annotators from different model families agreed on source/method tag on 91% of spans, content tag 69%; disagreements and sensitive tags routed to a specialist queue. Existing taxonomy: method/taxonomy.md (read it). Existing two-pane review screen and searchable index: web/app.html.
- Tools available: frontier models via CLI agents (several families), Python stdlib pipeline, static HTML/JSON front end. No GPU cluster. Small budget.
