MATCHING (src/build_reconcile.py, all at build time, deterministic):
1. Tokenize the source window into words with char offsets (split on whitespace). For each word store l1_normalize(word); ignore words whose normalized form is empty. Keep the layer of each word.
2. For annotation set 1: location = the exact span offsets. Color:
   - matched (green): every span's source[start:end] == span text AND no non-author layer lies between the unit's first and last span.
   - highlighted (orange): texts match but the unit skips non-author material in between (editor footnote/bracket), OR the unit starts or ends in the middle of a sentence (first char of unit is not preceded by sentence punctuation/newline, or last char not followed by one) — reason must say which.
   - discrepancy (red): any span text != source slice (should never happen; if it happens, show it).
3. For annotation set 2: split text on "..." or "…" into fragments. Align each fragment's normalized words to the source word list IN ORDER (each fragment searched after the previous fragment's end). Use difflib.SequenceMatcher on word lists; to avoid mis-anchoring short fragments, prefer windows that contain an exact 2-word anchor from the fragment, and choose the window with the highest ratio. Map aligned words back to raw char offsets. Color:
   - matched (green): one fragment, all words identical after l1_normalize, contiguous in source (diacritics/punctuation differences allowed — record "diacritics_or_punctuation_differ": true/false).
   - highlighted (orange): all words identical after l1_normalize but the text is elided (more than one fragment) or does not cover a full sentence; record the elided source ranges (gaps).
   - discrepancy (red): any word differs, is missing, or is extra. Record each difference {kind: variant|missing_in_annotation|extra_in_annotation, annotation_words, source_words, source_start, source_end}.
   Expected real cases (verify, do not hardcode): AK-007 has «القرآن» where the pinned source has «القرن», and «الأسفع» vs «الأسقع»; AK-001 has «قد» vs source «وقد»; several units are elided with "...".
4. Output web/reconcile_data.json: source window text (exact characters), word/offset table, layer ranges in window, both annotation sets with per-unit color, reasons, locations, differences, and the source sha256 (verified against manifest at build time — abort if mismatch).
5. Inline the JSON into src/reconcile_template.html -> web/reconcile.html (<script type="application/json" id="data">).
