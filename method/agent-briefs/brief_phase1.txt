src/fetch.py
- Save every raw HTTP response byte-for-byte to data/raw/<source>/<name>, plus data/raw/manifest.json with: url, timestamp UTC, http status, byte length, sha256.
- Then extract plain text per ayah per source into data/raw/<source>/<surah>_<ayah>.txt (UTF-8). For HTML in source B, strip tags with a small html.parser-based stripper; keep text content exactly otherwise. Record sha256 of each extracted .txt in the manifest too.

src/normalize.py — documented, rule-by-rule, each rule a separate function with a docstring:
- L0: raw (no change)
- L1: remove tashkeel (U+064B–U+065F, U+0670), tatweel (U+0640), collapse whitespace, strip Quranic/ornamental brackets ﴿﴾ «» "" and punctuation, remove footnote markers like (١) or [1], unify ﷺ with صلى الله عليه وسلم.
- Do NOT fold ة→ه, ى→ي, or hamza forms. Those differences must stay visible.

src/reconcile.py -> reports/reconciliation.md + reports/reconciliation.json
For each ayah: length A/B, exact match (L0) yes/no, match after L1 yes/no, similarity ratio (difflib) at L1, and a word-level diff at L1 listing every differing region (A text vs B text, max 30 regions, with position). Add a section "Independence": do A and B appear to share an upstream edition? Report what metadata says; do not guess — write "unknown" if unknown.

src/spans.py -> data/spans/<surah>_<ayah>.json using SOURCE A text only.
- Split the L0 text into numbered atomic spans by CODE: break after . ؟ ! : ؛ and newline; also break before markers «حديث آخر» «طريق أخرى» «وقوله» «وقال» «قال» when preceded by sentence end. Keep spans between ~5 and ~60 words; never split inside ﴿...﴾.
- Each span: {id: "s001", start: char_offset, end: char_offset, text}. Invariant check: "".join(span texts) == source text exactly (assert it). Offsets are into the exact source A file.

src/run_all.py runs fetch -> reconcile -> spans and prints a summary.
