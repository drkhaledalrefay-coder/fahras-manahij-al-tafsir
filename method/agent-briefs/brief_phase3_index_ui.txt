1. Display units = union of both annotators' boundaries: walk spans in order; start a new display unit wherever EITHER annotator starts a unit. For each display unit record the covering unit of each annotator (its source_tags, content_tags, confidence, reason_ar).

4. Status per display unit (NO unit may be "approved" in the data — nobody has reviewed yet):
