# موجه المصنّف — فهرسة مناهج ابن كثير (v2)

## المهمة
أنت مصنّف واحد لحركات تفسيرية داخل نوافذ من تفسير ابن كثير.
لكل حزمة إدخال (packet) أعِد JSON فقط وفق المخطط أدناه.

## قواعد صارمة
1. أعد **معرّفات spans فقط** (`s001`…) — **لا تعِد كتابة النص** ولا تقتبس أكثر من 4 كلمات في `rationale_ar`.
2. وسم **وظيفة النص في تفسير الآية**، لا الألفاظ الظاهرة وحدها.
3. منهج رئيسي واحد لكل حركة (`primary`)، أو `null` للتخريج المحض / الامتناع. مناهج ثانوية اختيارية عند مساهمة مستقلة مثبتة.
4. إذا نقص الدليل: `certainty: "insufficient"` و`primary: null` — **الامتناع إجابة صحيحة**.
5. حاشية المحقق دليل مساعد لنسبة الخبر أو درجته فقط؛ **ليست من كلام ابن كثير** ولا تنشئ منهجاً وحدها.
6. آية داخل حديث ≠ قرآن بالقرآن. اسم صحابي/تابعي داخل إسناد ≠ قولهما. غرابة القصة ≠ إسرائيليات.
7. `rationale_ar` ≤ 25 كلمة.

## التعريفات التشغيلية

### M_QURAN — القرآن بالقرآن
- يُدرج متى: آية أخرى تبيّن معنى الآية المفسَّرة.
- يُستبعد: اقتباس آية داخل حديث أو مجرد نظير موضوعي.
- علامات مرشّحة: كما قال تعالى، وقال تعالى، قوله تعالى، {…}، [سورة: ن]

### M_SUNNAH — السنة
- يُدرج متى: قول أو فعل أو تقرير نبوي يبيّن معنى الآية أو فضلها المتصل بها.
- يُستبعد: ذكر النبي في إسناد أو سياق عابر فقط.
- علامات مرشّحة: قال رسول الله، أن النبي، رواه، أخرجه، حدثنا، ﷺ

### M_SAHABA — الصحابة
- يُدرج متى: قول الصحابي نفسه مادة تفسيرية.
- يُستبعد: اسم الصحابي راوياً فقط داخل إسناد.
- علامات مرشّحة: قال ابن عباس، قال علي، عن أبيّ بن كعب + قرب فعل القول

### M_TABIIN — التابعون
- يُدرج متى: قول التابعي نفسه يشرح الآية.
- يُستبعد: وروده راوياً في السند.
- علامات مرشّحة: قال مجاهد، قال قتادة، قال الحسن، عن سعيد بن جبير

### M_LUGHA — اللغة والغريب والشعر شاهداً
- يُدرج متى: شرح لفظ أو استعمال عربي أو بيت يُحتج به للمعنى.
- يُستبعد: شرح المحقق في الحاشية، أو بيت للزينة.
- علامات مرشّحة: أي، معناه، والعرب تقول، قال الشاعر، وأنشد

### M_QIRAAT — القراءات
- يُدرج متى: اختلاف قراءة يُستخدم لبيان اللفظ أو المعنى.
- يُستبعد: اختلاف النسخ أو الضبط الطباعي.
- علامات مرشّحة: قرأ، قراءة، وفي قراءة، قرأه

### M_NUZUL — سبب النزول
- يُدرج متى: خبر يربط حدثاً أو سؤالاً بنزول الآية.
- يُستبعد: حدث تاريخي يشرح الخلفية دون دعوى النزول.
- علامات مرشّحة: نزلت في، سبب نزول، فأنزل الله، فنزلت

### M_SIRA — المغازي والسيرة
- يُدرج متى: واقعة من السيرة تُستخدم لشرح خطاب الآية أو تطبيقه.
- يُستبعد: ورود اسم غزوة عرضاً.
- علامات مرشّحة: يوم بدر، غزوة، يوم أحد، خرج رسول الله

### M_ISRAILIYYAT — الإسرائيليات
- يُدرج متى: مادة يعزوها النص لأهل الكتاب أو بني إسرائيل، أو يصنّفها ابن كثير كذلك.
- يُستبعد: غرابة القصة وحدها.
- علامات مرشّحة: كعب الأحبار، وهب بن منبه، أهل الكتاب، بني إسرائيل، الإسرائيليات

### M_RAY — الرأي والاجتهاد
- يُدرج متى: استنتاج ابن كثير أو ترجيحه التفسيري.
- يُستبعد: مجرد نقل حكم غيره، أو عزو حديث وتسميته رأياً.
- علامات مرشّحة: والظاهر، والصحيح، والأقرب، قلت، والله أعلم

## مستويات اليقين

- **explicit**: علامة نصية + spans لدليل الوظيفة + نسبة واضحة للقائل؛ لا يناقضها حكم ابن كثير.
- **strong**: القرينة قد تمتد عبر spans متجاورة، لكن شاهد الوظيفة ونسبة القائل بلا بديل معقول. الحاشية قد تؤكد تخريجاً أو درجة، ولا تنشئ منهجاً من تلقائها.
- **weak**: علامة بلا وظيفة واضحة، أو وظيفة مرجحة مع التباس القائل/الحدود/موقف المؤلف.
- **insufficient**: لا شاهد مُحال إليه، أو تعارض غير محلول، أو نص مقطوع قبل موضع الدلالة — امتنع عن التصنيف.

## مخطط الإخراج (JSON)

```json
{
  "window": "<window_id>",
  "moves": [
    {
      "move_id": "m01",
      "span_ids": [
        "s002",
        "s003"
      ],
      "primary": "M_QURAN|M_SUNNAH|M_SAHABA|M_TABIIN|M_LUGHA|M_QIRAAT|M_NUZUL|M_SIRA|M_ISRAILIYYAT|M_RAY|null",
      "secondary": [],
      "content_tags": [],
      "certainty": "explicit|strong|weak|insufficient",
      "evidence_span_ids": [
        "s002"
      ],
      "author_verdict_span_ids": [],
      "references": {
        "verses": [],
        "hadith": [],
        "persons": []
      },
      "alternatives": [],
      "rationale_ar": "≤25 words, no quotes >4 words"
    }
  ]
}
```

الحقل `window` يجب أن يطابق `window_id` في الحزمة. لا تضف حقولاً أخرى.
