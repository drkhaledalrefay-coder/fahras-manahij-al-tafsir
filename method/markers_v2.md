# علامات المنهج الآلية (v2)

كشف حتمي بالكود فقط. المقارنة تجري على نصٍ أُزيلت منه الحركات (U+064B–U+065F و U+0670)؛ الإزاحات المعادة هي إزاحات المصدر الأصلي. النص المصدر لا يُعدَّل.

| العائلة | الأنماط / القائمة | ملاحظات |
|---|---|---|
| **QURAN** | اقتباس `{…}` أو `﴿…﴾`؛ عبارات: `كما قال تعالى`، `وقال تعالى`، `قوله تعالى`، `قال تعالى`، `وقوله تعالى`، `لقوله تعالى`؛ و`verse_ref` من طبقة الطبقات `[سورة: n]` المجاورة مباشرة بعد الـspan (فجوة ≤3 محارف). | علامة مرشِّحة فقط؛ الوظيفة التفسيرية يحسمها المصنّف. |
| **HADITH** | `قال رسول الله`، `أن النبي` / `ان النبي`، `أن رسول الله` / `ان رسول الله`، `رواه`، `أخرجه`، `في الصحيح`، `حدثنا`، `أخبرنا` / `اخبرنا`، `صلى الله عليه وسلم`، والرمز `ﷺ`. | يشمل صيغ التخريج والعزو. |
| **SAHABA** | أسماء: ابن عباس، ابن مسعود، علي، عمر، أبو بكر، عثمان، أبي بن كعب، أبو هريرة، عائشة، ابن عمر، أنس، جابر، أبو ذر، أبو سعيد، معاذ، أبو موسى الأشعري، عبد الله بن عمرو، أبو أمامة. | لا يكفي الاسم داخل سند؛ «أبو سعيد الأشج» ليس الصحابي أبا سعيد. |
| **TABIIN** | مجاهد، قتادة، الحسن، الحسن البصري، سعيد بن جبير، عكرمة، الضحاك، السدي، عطاء، الربيع، أبو العالية، أبو مالك، ابن زيد، زيد بن أسلم، ابن جريج، محمد بن كعب القرظي، إبراهيم النخعي، الشعبي، كعب الأحبار، علي بن أبي طلحة (يُوسم ناقلاً). | كعب المتكلم يولّد أيضاً علامة **ISRAILIYYAT**. |
| **ISNAD** | سلسلة `عن X عن Y` (تكرار `عن` ≥2)؛ أو تكرار `حدثنا`/`أخبرنا` مع أسماء. | تُوسم الأسماء الوسيطة `NARRATOR`، والاسم الأخير قبل القول أو «في قوله» أو النص المقتبس `SPEAKER` بحسب قائمة الصحابة/التابعين؛ وإذا كان الأخير النبي ﷺ فالعائلة **HADITH**. |
| **LUGHA** | `أي:` / `اي:`، `معناه`، `يقال`، `والعرب تقول`، `في اللغة`، `قال الشاعر`، `وأنشد`، `كقوله`، `كقول`. | |
| **QIRAAT** | `قرأ`، `قراءة`، `وفي قراءة`، `قرأه`. | |
| **NUZUL** | `نزلت في`، `سبب نزول`، `فأنزل الله`، `فنزلت`، `فأنزل`. | |
| **SIRA** | `يوم بدر`، `غزوة`، `يوم أحد`، `خرج رسول الله`. | |
| **ISRAILIYYAT** | `كعب الأحبار`، `وهب بن منبه`، `أهل الكتاب`، `بني إسرائيل`، `الإسرائيليات`، `من كتبهم`، `كتب بني إسرائيل`. | |
| **RAY** | `والأظهر`، `والظاهر`، `والصحيح`، `قلت`، `والله أعلم`، `والراجح`، `وهذا أولى`، `والمعنى`، وكذلك `والأقرب`، `وأقرب`، `وهذا إسناد`، `غريب`، `فيه نظر`. | حكم المؤلف / ترجيحه (مقارنة بلا حركات). |
| **EDITOR** | كل مدى `footnote` من الطبقات يُربط بأقرب span مؤلف سابق؛ تُلتقط كلمات التصحيح `صحيح`، `حسن`، `ضعيف`، `سنده`، `إسناده`. | دليل مساعد فقط — ليست منهجاً بذاتها. وسم الحقل: `editor_footnote`. |

التنفيذ: `src/v2_markers.py` → `data/v2/markers/<window_id>.json`.

تقبل نسبة القول، بعد حذف الحركات، الصيغتين `قال X` و`X قال`، وكذلك `عن X قال`، `عن X أنه قال`، `عن X في قوله`، `روي عن X` مع الواو أو بدونها، `وكذا قال X`، `وهكذا قال X`، `ونحوه عن X`، `مثله عن X`، `وهو قول X`، `قاله X`، و`من طريق … عن X`. والنص المنتهي بـ`عن X:` قد تتبعه المقولة في الـspan التالي. وتُحفظ إزاحات الاسم في النص الأصلي مع حقل `role`.

في التحقق من **M_SAHABA** و**M_TABIIN** يُشترط `SPEAKER` من العائلة المطلوبة في شواهد الحركة أو في الـspan السابق مباشرة لأول شاهد. ظهور الاسم ناقلاً في وسط السند فقط لا يفي بالشرط. يظل فحص `rule_editor_only_evidence` قائماً، ولا يُطلق إذا وُجدت علامة متكلم من طبقة المؤلف.
